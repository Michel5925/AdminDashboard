# Admin Dashboard

A responsive admin dashboard interface built with **HTML and CSS** as part of my learning journey.

The project focuses on creating a structured dashboard layout with a sidebar navigation, header, project cards, announcements, trending users and responsive styling.

## Features

* Dashboard overview
* Project cards
* Announcements section
* Trending section
* User profile and greeting
* Sidebar navigation
* Settings, support and privacy navigation
* Home, profile, messages, history, tasks and communities sections
* New, Upload and Share buttons
* Custom dashboard styling
* Responsive layout
* Custom SVG icons and images

## Technologies

* **HTML5** — Dashboard structure and content
* **CSS3** — Layout, styling and responsive design
* **Flexbox** — Page and component layout
* **CSS Grid** — Dashboard and project layout
* **SVG** — Navigation icons

## Dashboard Layout

The dashboard is divided into several main areas:

### Sidebar

The sidebar contains navigation options including:

* Dashboard
* Home
* Profile
* Messages
* History
* Tasks
* Communities
* Settings
* Support
* Privacy

### Header

The header contains:

* Search area
* User profile
* Personal greeting
* New button
* Upload button
* Share button

### Projects

The main content area contains several project cards displaying project names and descriptions.

### Announcements

The announcements section displays information such as:

* Site Maintenance
* Community Share Day
* Updated Privacy Policy

### Trending

The trending section displays users and their associated projects.

## Design

The project focuses on creating a clean dashboard-style interface with clearly separated sections.

CSS Grid and Flexbox are used together to organise the dashboard, allowing the sidebar, header, projects and sidebar content to fit into a structured layout.

## How to Run

### 1. Clone the repository

```bash
git clone https://github.com/Michel5925/AdminDashboard.git
```

### 2. Navigate into the project

```bash
cd AdminDashboard
```

### 3. Open the application

Open `index.html` in your browser.

No additional dependencies or installation steps are required.
